
# 🌟 Portfolio Website by Imtisal Adeel

A modern, high-performance personal portfolio website built with semantic **HTML5**, custom **CSS3**, and **JavaScript (ES6+)**. Designed to highlight frontend development projects, web design assets, and digital creations with a sleek dark-themed layout.

---

## 🚀 Live Demo

* **Live Portfolio:** (https://imtii56.github.io/codealpha_tasks/)
* **Project Showcase:** Includes live links to academic platforms, interactive tools, and UI/UX prototypes.

---

## ✨ Key Features

* **📱 Responsive Layout:** Mobile-first, fully responsive layout engineered with CSS Flexbox & Grid.
* **🎨 Modern Aesthetics:** Dark theme styling with glowing elements and interactive hover states.
* **⏰ Real-Time Clock:** Dynamic JavaScript-powered digital navbar clock.
* **✍️ Animated Typing Effect:** Hero section powered by Typed.js library.
* **📦 Bento Grid Layout:** Clean skills display using modern Bento Grid structural architecture.
* **📩 Functional Contact Form:** Integrated with **Web3Forms** API for direct client messaging.
* **🖼️ Interactive Service Cards:** Expanding "Read More" functionality for detailed service descriptions.

---

## 🛠️ Tech Stack & Tools

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Libraries & Icons:** Typed.js, Font Awesome Icons
* **UI/UX Tools:** Figma (Design System & Prototyping)
* **Form Handler:** Web3Forms API
* **Version Control:** Git, GitHub
